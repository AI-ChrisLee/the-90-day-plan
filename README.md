# The 90-Day Plan

A Claude Code skill that turns your first week of real data into a lane, a
plan, and a morning ritual. It reads your Warm CRM, your call grades, and your
offer card, recommends ONE lane with the why (you decide), writes your 90 days
on the Rule of 100, and then runs your mornings: reviews your log, asks one
question, prints today's tasks. You read, fix one thing, and go.

Sundays it fills your weekly row and runs the Execution Algorithm on your week:
what to delete, and one change for next week.

It never sends anything and never decides for you.

Built and used by [AI Chris Lee](https://www.youtube.com/@aichrislee). Part of
the Execution Squad system. Skills update every season; pull fresh when you run.

## Install (one minute)

```
Install this skill: https://github.com/AI-ChrisLee/the-90-day-plan
Clone it into my skills folder as the-90-day-plan.
```

Then open a NEW session.

```bash
git clone https://github.com/AI-ChrisLee/the-90-day-plan ~/.claude/skills/the-90-day-plan
```

## Run it

```
/the-90-day-plan
```

Or say: "Pick my lane and build my 90-day plan." Every morning after:
"Run my morning."
